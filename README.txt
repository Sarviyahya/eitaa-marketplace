# بازارچه ایتا — پیش‌نمایش رابط کاربری

این بسته یک نمونه اولیه فرانت‌اند برای برنامک بازارچه ایتا است.

## اجرا
- فایل `index.html` را در مرورگر باز کنید.
- جست‌وجو، دسته‌بندی، فیلتر استان/شهر و فرم ثبت آگهی را آزمایش کنید.
- اطلاعات نمونه و آگهی‌های تازه در localStorage همان مرورگر ذخیره می‌شوند.

## محدودیت مهم
این نسخه هنوز به ایتا، ربات، پایگاه داده مرکزی یا فضای ذخیره‌سازی تصاویر متصل نیست. localStorage فقط برای آزمایش رابط است و برای سامانه واقعی مناسب نیست.
برای انتشار به‌عنوان برنامک، فایل باید روی HTTPS میزبانی و در پنل توسعه‌دهندگان/ایتایار ثبت شود. سپس باید:
1. سرور API و پایگاه داده راه‌اندازی شود.
2. اعتبارسنجی امضای `window.Eitaa.WebApp.initData` در سمت سرور پیاده‌سازی شود.
3. آپلود امن تصاویر و کنترل نوع/حجم فایل افزوده شود.
4. توکن ربات فقط در سرور نگهداری شود.
5. مجوز ارسال و ویرایش پیام کانال با حساب و کانال واقعی آزمایش شود.
